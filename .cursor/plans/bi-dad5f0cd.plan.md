# План доработки BI системы анализа бизнеса

## Цели

1. Обеспечить сквозные данные (одинаковые данные во всех закладках и инструментах)
2. Реализовать рабочие алгоритмы расчета для всех 24 инструментов
3. Синхронизировать графики с фактическими данными
4. Создать генерацию тестовых данных с правильной структурой и распределением по инструментам
5. Обеспечить правильное использование данных из одного инструмента в другом

## Анализ текущих проблем

### Проблема 1: Нет сквозных данных

- Frontend использует статичные данные из `unifiedFinancialData.ts`
- Backend генерирует данные, но они не связаны с frontend
- `InstrumentSpecificFields` работает независимо от других компонентов
- Данные из `DataEntryPanel` не попадают в графики и другие инструменты

### Проблема 2: Инструменты расчета не работают

- Конфигурация инструментов есть, но алгоритмы расчета отсутствуют
- `autoCalculatedData` не заполняется автоматически
- Нет сервисов расчета на backend

### Проблема 3: Графики не соответствуют данным

- Графики используют статичные мок-данные
- Реальные данные из API игнорируются
- Нет реактивности при изменении данных

## Этапы реализации

### Этап 1: Создание единого источника данных (Centralized Data Store)

**Задачи:**

1. Создать сервис `DataService` на frontend для управления всеми финансовыми данными
2. Создать API endpoints на backend для синхронизации данных
3. Интегрировать React Query для кэширования и синхронизации
4. Заменить статичные данные на данные из API

**Файлы для изменения:**

- `FinFlowAI/client/src/services/dataService.ts` (новый)
- `FinFlowAI/server/routes.ts` - добавить endpoints для получения/сохранения данных
- `FinFlowAI/client/src/pages/Dashboard.tsx` - использовать DataService вместо статичных данных
- `FinFlowAI/client/src/components/DataEntryPanel.tsx` - синхронизация с DataService

### Этап 2: Реализация генерации тестовых данных

**Задачи:**

1. Создать сервис генерации тестовых данных на backend
2. Генерировать иерархию периодов (год → кварталы → месяцы → дни)
3. Распределять данные по всем инструментам согласно их конфигурации
4. Создавать связи между данными разных инструментов
5. Генерировать реалистичные данные с правильными зависимостями

**Файлы для изменения:**

- `FinFlowAI/server/services/testDataGenerator.ts` (новый)
- `FinFlowAI/server/routes.ts` - добавить endpoint `/api/test-data/generate`
- `FinFlowAI/server/storage.ts` - методы для создания периодов и данных

### Этап 3: Реализация расчетных алгоритмов

**Задачи:**

1. Создать сервис расчетов для каждого инструмента
2. Реализовать алгоритмы из `script.py` для основных инструментов:

- ДДС классический (dds_klassicheskiy)
- Финансовая модель (finansovaya_model)
- И другие инструменты по приоритету

3. Автоматически рассчитывать `autoCalculatedData` при сохранении `manualInputData`

**Файлы для изменения:**

## Приоритеты реализации

1. **Высокий приоритет:**

- Единый источник данных (Этап 1)
- Генерация тестовых данных (Этап 2)
- Расчетные алгоритмы для 3 основных инструментов (Этап 3, частично)

2. **Средний приоритет:**

- Остальные расчетные алгоритмы (Этап 3, полностью)
- Синхронизация между инструментами (Этап 4)
- Исправление визуализации (Этап 5)

3. **Низкий приоритет:**

- Оптимизация и доработка деталей (Этап 6)

## Критерии готовности

1. ✅ Тестовые данные генерируются и сохраняются в правильной структуре
2. ✅ Данные отображаются одинаково во всех закладках и инструментах
3. ✅ Расчетные алгоритмы работают для основных инструментов
4. ✅ Графики показывают реальные данные
5. ✅ Изменение данных в одном инструменте обновляет зависимые инструменты
6. ✅ Все данные синхронизируются между frontend и backend

## Технические детали

### Структура данных

- Использовать существующую схему `instrumentData` с полями:
- `manualInputData` - данные ручного ввода
- `editableCalculationData` - параметры расчета
- `autoCalculatedData` - рассчитанные данные

### API Endpoints

- `GET /api/financial-data` - получить данные
- `POST /api/financial-data` - сохранить данные
- `POST /api/test-data/generate` - сгенерировать тестовые данные
- `POST /api/calculations/calculate` - выполнить расчеты
- `POST /api/data/sync` - синхронизировать данные между инструментами

### Зависимости между инструментами

- Финансовая модель использует данные из ДДС
- Платежный календарь использует данные из финансовой модели
- Все инструменты используют базовые финансовые данные (выручка, расходы, прибыль)
